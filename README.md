# Xia’s Jarvis

Private, local-first installable personal command centre.

## This build
- Installable PWA for Android Chrome and desktop Chrome/Edge.
- Persists signals, missions, approvals and local chat in the browser on each device.
- Works offline after first load.
- Uses the approved sparse command-core Home HUD.
- Makes calls and task creation approval-first: it never sends or calls automatically.
- Can export a local JSON backup and use browser speech recognition where Chrome offers it.

## Deliberate boundaries
This build does not yet sync between devices or read notifications, messages, calendar or contacts. It does not contain credentials or connect to external AI.

## Next layers
1. Secure sign-in and encrypted cross-device sync.
2. Native Android companion for permissions.
3. Official OAuth integrations.
4. Hosted AI with explicit privacy and approval boundaries.
